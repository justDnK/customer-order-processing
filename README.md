В проекте созданы две сущности: user, customer. 
User - это сущность пользователя на сайте, может иметь роли client, manager.  
Customer - это сущность покупателя, он может не быть зарегистрированным на сайте, 
но может быть зарегистрированным менеджером так как все клиенты должны быть в системе и иметь карточки с информацией.
Но если клиент (Customer) захочет зарегистрироваться он автоматически становится Customer.
